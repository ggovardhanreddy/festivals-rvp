## GitHub is the CMS

## Local development

```bash
cp .env.example .env.local   # fill R2 + admin secrets as needed
npm install
npm run sync
npm run dev
```

| Command | Purpose |
|---|---|
| `npm run sync` | Scan `content/`, optimize media, write `generated/albums.json` |
| `npm run generate` | Search index, sitemap, feed, manifest |
| `npm run validate` | Pre-deploy quality gate |
| `npm run typecheck` | TypeScript |
| `npm run lint` | ESLint |
| `npm run test` | Smoke tests |
| `npm run build` | Full production build |
| `npm run admin-hash -- "password"` | Generate `ADMIN_PASSWORD_HASH` |
| `npm run media:migrate:r2` | Upload `public/` media to Cloudflare R2 |
| `npm run deploy:cf` | Build, strip local media (when R2 set), deploy Pages |

## Super Admin

- URL: `/admin/` (also **Super Admin** in the site menu)
- Secrets (Cloudflare Pages → Settings → Environment variables / secrets):
  - `SUPER_ADMIN_USERNAME`
  - `ADMIN_PASSWORD_HASH` (from `npm run admin-hash`)
  - `ADMIN_SESSION_SECRET`
- Members roster, photos, memorials, and community collections can be managed in the dashboard and stored in R2.

## Cloudflare R2 media

Large gallery/video files are stored in **Cloudflare R2** (`reddivaripalli` bucket). Cloudflare Pages hosts only the app shell (25 MiB file limit).

1. Enable R2 + create/use bucket `reddivaripalli`
2. Enable public access (`npx wrangler r2 bucket dev-url enable reddivaripalli --force`) or attach `media.reddivaripalli.com`
3. Set `NEXT_PUBLIC_R2_PUBLIC_URL` / `R2_PUBLIC_BASE` / `MEDIA_SIGNING_SECRET` (see `.env.example`)
4. Bind the bucket as `MEDIA` in `wrangler.toml` (already configured)
5. `npm run media:migrate:r2` then `npm run deploy:cf`

Full guide: [docs/13-R2_MEDIA.md](./docs/13-R2_MEDIA.md) · env template: [.env.example](./.env.example)
